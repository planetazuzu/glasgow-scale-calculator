# Calculadora de Escala de Coma de Glasgow (GCS)

Herramienta para calcular la Escala de Coma de Glasgow y evaluar el nivel de consciencia en pacientes con daño cerebral.

## Descripción

La Escala de Coma de Glasgow (GCS) es un método utilizado por profesionales médicos para evaluar el nivel de consciencia en pacientes después de un traumatismo craneoencefálico. Esta herramienta proporciona una manera fácil y rápida de calcular la puntuación GCS basada en tres componentes:

1. **Apertura ocular** (1-4 puntos)
2. **Respuesta verbal** (1-5 puntos)
3. **Respuesta motora** (1-6 puntos)

La suma de estos tres valores da un resultado entre 3 y 15 puntos, que se clasifica en:
- **Leve**: 13-15 puntos
- **Moderado**: 9-12 puntos
- **Grave**: 3-8 puntos

## Versiones disponibles

Este proyecto incluye dos versiones:

1. **Versión de línea de comandos** - Un programa Python simple que se ejecuta en la terminal
2. **Aplicación Android** - Una versión móvil desarrollada con Kivy

## Instrucciones de uso

### Versión de línea de comandos

Para ejecutar la versión de línea de comandos:

```bash
python glasgow_coma_scale.py
```

Sigue las instrucciones en pantalla para ingresar los valores de cada componente.

### Aplicación Android

Para utilizar la aplicación Android:

1. Instala el APK en tu dispositivo Android
2. Abre la aplicación "Calculadora GCS"
3. Utiliza los deslizadores para seleccionar los valores de cada componente
4. Presiona "Calcular" para obtener el resultado

## Notas importantes

- Esta herramienta está diseñada como ayuda para profesionales médicos y estudiantes.
- No reemplaza el juicio clínico profesional.
- La Escala de Coma de Glasgow es parte de una evaluación más amplia del paciente.
