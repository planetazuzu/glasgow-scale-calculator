# Archivos del proyecto Calculadora GCS para Android

Este proyecto contiene los siguientes archivos que debes descargar para compilar la aplicación Android:

## Archivos principales
- `main.py` - Punto de entrada de la aplicación
- `gcs_app.py` - Implementación principal de la interfaz con Kivy
- `buildozer.spec` - Configuración para la compilación Android

## Archivos de apoyo
- `compilar_apk.sh` - Script de ayuda para la compilación
- `INSTRUCCIONES_COMPILACION.md` - Guía paso a paso para compilar
- `README_ANDROID.md` - Información técnica sobre la app Android
- `README_ES.md` - Información en español sobre la aplicación
- `README.md` - Información general del proyecto

## Archivos opcionales
- `glasgow_coma_scale.py` - Versión de línea de comandos original
- `generated-icon.png` - Icono para la aplicación

## Pasos para descargar
1. Descarga cada archivo individualmente desde Replit
2. Asegúrate de mantener los nombres exactos de los archivos
3. Coloca todos los archivos en una misma carpeta
4. Sigue las instrucciones en INSTRUCCIONES_COMPILACION.md

## Requisitos mínimos del sistema
- Ubuntu 20.04/22.04 (recomendado) o sistema compatible
- Python 3.7+
- 4GB RAM (8GB recomendado)
- Espacio libre en disco: 5GB 
- Conexión a Internet (para descargar dependencias)
