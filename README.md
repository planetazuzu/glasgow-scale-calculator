# Glasgow Scale Calculator (Unified Repository)

Este repositorio unifica dos implementaciones diferentes de la calculadora de la Escala de Coma de Glasgow (GCS) para emergencias sanitarias:

## 📂 Estructura del Repositorio

1. **`./` (Raíz)**:
   - **Aplicación Web**: Desarrollada en **React + Vite + Tailwind CSS**.
   - Optimizada para navegadores móviles y web progresivas (PWA).

2. **`./python-version/`**:
   - **Aplicación Python / Android (Kivy)**: Versión de escritorio y móvil empaquetable mediante Buildozer para APK.
   - Contiene los scripts originales de Python (`glasgow_coma_scale.py`, `gcs_app.py`, etc.).
